
# Planificador de Tareas Web

## Autor

**Juan Andres Bohórquez Acevedo**

## Descripción del proyecto

**Planificador de Tareas Web** es una aplicación que permite organizar y gestionar tareas diarias de forma simple e intuitiva. 

El usuario puede crear nuevas tareas con título, descripción, fecha de entrega, prioridad y categoría; marcarlas como completadas mediante un checkbox; y eliminarlas con confirmación.
